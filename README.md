# Выявление экономической структуры российских муниципалитетов с использованием кластеризации на атрибутированных сетях

Исследование потребительско-экономической структуры муниципальных образований России с помощью кластеризации и анализа динамической сети сходства. Цель — выделить интерпретируемые типы муниципалитетов, проследить их изменение во времени и сопоставить полученную типологию с внешними социально-экономическими характеристиками.

**[Интерактивная страница с результатами](https://vladbiserov.github.io/sber-hack/)** · **[Методологический отчёт](METHODOLOGY.md)**

## Кратко о проекте

- **2 016 муниципалитетов**, **24 месяца**: январь 2023 — декабрь 2024 года.
- **6 категорий потребительских расходов** по данным СберИндекса.
- **4 экономических типа**, определённых по структуре потребления.
- **24 взвешенных графа** сходства муниципалитетов (по одному на месяц).
- Сравнение **K-Means, Spectral Clustering и Leiden**; итоговый вариант — **Temporal K-Means** с графовой и временной регуляризацией.
- Внешняя интерпретация по показателям **БДМО Росстата** и индексу доступности рынков СберИндекса.

Это **типология по структуре безналичного потребления**, а не классификация муниципалитетов по отраслям производства.

## Подход и основные результаты

Для каждого месяца шесть долей расходов преобразуются методом **CLR** (*centered log-ratio*). На основе расстояний в CLR-пространстве формируется взвешенный граф `union-kNN` с `k = 10`. Итоговые месячные метки строятся методом Temporal K-Means для четырёх кластеров с графовым штрафом `β = 0,15` и временным штрафом `λ = 0,25`.

На декабрь 2024 года выделены следующие группы:

| Тип | Интерпретация | Муниципалитетов |
|---|---|---:|
| 0 | Продовольственно-ориентированный, с умеренно пониженной деловой активностью | 651 |
| 1 | Высокоплотный, с повышенной оплатой труда и долей прочих расходов | 455 |
| 2 | Продовольственно-маркетплейсный, с пониженными годовыми показателями | 334 |
| 3 | Промежуточный потребительский, с умеренно повышенной занятостью | 576 |

Медианный ARI разбиений соседних месяцев составляет **0,848** у Temporal K-Means против **0,760** у независимой K-Means при близком Silhouette (**0,296** против **0,299**). При этом отдельный вклад графовой регуляризации небольшой: удаление графового штрафа изменяет **176 из 48 384** месячных назначений.

Подробности преобразований, критериев качества, экспериментов и ограничений приведены в **[METHODOLOGY.md](METHODOLOGY.md)**.

## Просмотр интерактивной страницы

Страница находится в корневом файле **`index.html`**. Она автономна: необходимые данные и визуализации встроены в HTML. 

## Структура репозитория

```text
.
├── index.html                 # Интерактивная страница с результатами
├── METHODOLOGY.md             # Научно-методологический отчёт
├── README.md                  # Описание и запуск
├── requirements.txt           # Python-зависимости
├── configs/                   # Параметры данных, графов и экспериментов
├── data/
│   ├── raw/                   # Исходные данные СберИндекса и справочники
│   └── reviewed_raw/          # Проверенные локальные выгрузки БДМО
├── src/                       # Модули подготовки данных, графов и кластеризации
├── notebooks/                 # Поэтапное исследование (01–12)
├── outputs/                   # Матрицы признаков, графы, метки, метрики, профили
└── reports/                   # Диагностика признаков и покрытия данных
```

Состав каталогов `data/`, `outputs/` и `reports/` зависит от того, какие исходные данные и промежуточные результаты включены в опубликованную версию репозитория.

## Воспроизведение расчётов

Откройте файлы из папки `notebooks/` и выполняйте ячейки сверху вниз:

| Этап | Ноутбук | Результат |
|---|---|---|
| 01 | `01_sber_base.ipynb` | Загрузка и проверка данных СберИндекса |
| 02 | `02_load_bdmo.ipynb` | Каталог и загрузка показателей БДМО |
| 03 | `03_audit.ipynb` | Контроль покрытия и отбор показателей |
| 04 | `04_features.ipynb` | Месячные и годовые матрицы признаков |
| 05 | `05_feature_analysis.ipynb` | Проверка признакового пространства и CLR |
| 06 | `06_graph_construction.ipynb` | Выбор графа и сохранение 24 месячных графов |
| 07 | `07_clustering.ipynb` | Сравнение K-Means, Spectral и Leiden |
| 08 | `08_temporal_clustering.ipynb` | Согласование месяцев и временная регуляризация |
| 09 | `09_validation.ipynb` | Метрики качества кластеризации |
| 10 | `10_economic_interpretation.ipynb` | Экономические профили и представители типов |
| 11 | `11_robustness.ipynb` | Устойчивость и сохранение итоговых меток |
| 12 | `12_graph_validation.ipynb` | Проверка самостоятельного вклада графового штрафа |

**Контрольные настройки финальной модели:**

- В `configs/graph_experiment.json` выбраны `method = "union"`, `representation = "clr"`, `window = 1`, `k = 10`. На этапе 06 после проверки эксперимента необходимо **выполнить сохранение через `save_sequence(...)`**. Перед этапом 07 должны появиться `outputs/bdmo_v3/graphs_step06/manifest.json` и 24 файла `graph_YYYY-MM.npz`.
- В `configs/clustering_experiment.json` основной выбор: `selected_parameters.kmeans = 4`, `temporal_08.graph_beta = 0.15`, `temporal_08.selection = 0.25`. Без выбранной `selection` этап 08 не сохраняет результаты.
- Для фиксации финального результата этапа 11 после проверки экспериментов установите `robustness_11.save_enabled = true`. Этап 12 является диагностическим и **не должен автоматически заменять** итоговые метки этапа 11.

## Источники и ограничения

- **СберИндекс** — муниципальные оценки безналичных расходов, доступность рынков и территориальные справочники.
- **Росстат, БДМО** — муниципальные социально-экономические показатели за 2023–2024 годы.
- **Муниципальная геометрия** — справочные границы, используемые для картографической визуализации.

Годовые данные БДМО и доступность рынков используются **для внешней интерпретации**, а не для назначения итоговых кластерных меток. Временное сглаживание ретроспективное, поэтому результаты не являются прогнозом. Статистические связи между типами и экономическими показателями не доказывают причинность.

Дополнительное описание источников, формул и ограничений — в **[методологическом отчёте](METHODOLOGY.md)**.
